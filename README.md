# VISD Project Page Skeleton

This directory is a static GitHub Pages project page scaffold.

## File Map

- `index.html`: page structure and section placeholders.
- `styles.css`: visual layout, responsive styles, and TL;DR block styling.
- `assets/logos/`: put the top-left project icon here.
- `assets/figures/`: put teaser, motivation, and method figures here.
- `assets/results/`: put tables, plots, and benchmark figures here.
- `assets/analysis/`: put ablations and qualitative case studies here.

## Recommended Section Order

1. Hero: title, author list, institution list, links, and teaser figure.
2. TL;DR: one short paragraph like the reference page.
3. Abstract.
4. Motivation.
5. Method.
6. Experimental Results.
7. Analysis.
8. Citation.

## GitHub Pages URL

You need a GitHub repository to get a `github.io` URL.

Option A: user site URL

- Repository name: `<username>.github.io`
- URL: `https://<username>.github.io/`
- Put this project page at the repository root.

Option B: project site URL

- Repository name: any project repo, for example `VISD`
- URL: `https://<username>.github.io/VISD/`
- Put this project page at the repository root and enable Pages for the repo.

In GitHub: `Settings` -> `Pages` -> `Build and deployment` -> select `Deploy from a branch`, then choose `main` and `/root`.
